# ÉTALON — ETL

> *1 ETL = ce que valait 1 euro de pouvoir d'achat le jour du premier bloc.*

**FR** — La première monnaie communautaire indexée sur le pouvoir d'achat réel des Français.
**EN** — The first community currency indexed to real French purchasing power.

---

## Pourquoi / Why

**FR** — Depuis l'abandon de l'étalon-or, aucune monnaie ne protège votre pouvoir d'achat. L'ETL change ça — ancré sur l'IPC France entière (INSEE), géré par la communauté, sans banque, sans état.

**EN** — Since the end of the gold standard, no currency protects your purchasing power. ETL changes that — anchored to the French CPI (INSEE), governed by the community, without banks, without states.

---

## Ne faites pas confiance. Vérifiez. / Don't trust. Verify.

Le code est public. Chaque transaction est vérifiable. Chaque mise à jour IPC est vérifiable sur le site de l'INSEE.

The code is public. Every transaction is verifiable. Every IPC update is verifiable on the INSEE website.
